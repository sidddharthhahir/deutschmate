# FRICTION.md

One line every time studying actually annoys you. **This file is the backlog.**

Format: `YYYY-MM-DD — what annoyed you`

Not: "it would be cool if…". Only: "I was studying and this got in my way."

---

## The rule

A feature enters the roadmap when **one** of these is true:

- it is written below, by someone who hit it while studying, or
- three people have asked for it independently, or
- it is required to keep an existing promise (the principles in the README).

Nothing else. Not because ideas are bad — because ideas are infinite and hours
are not, and the ones that arrive during a planning session are selected for
sounding good rather than for mattering.

**The evidence for this is in the repo.** The single most valuable pass over
this project found a recap reporting `0 Minuten · 0 neue Wörter · 0 %` on the
screen the code itself calls "the screen that decides whether you come back
tomorrow". No amount of reading the code would have found it: the database had
the numbers all along, and `requestAnimationFrame` does not run in a background
tab. It was found by finishing a session and locking a phone.

Three reviews of this project have proposed features. Zero of them found that.

The second most valuable pass was deleting the comments — 5,677 lines down to
1,810. It was not looking for bugs. It found two, including a cookie every
learner shared, because reading a line against what the comment above it claims
is a code review nobody schedules. Neither is a feature. Both are the kind of
thing this file exists to keep ahead of.
